# SOOP 구간 재생 확장 프로그램

## 설치

1. Chrome에서 `chrome://extensions`를 연다.
2. **개발자 모드**를 켠다.
3. **압축해제된 확장 프로그램을 로드합니다**에서 이 `01_src` 폴더를 선택한다.

## 사용

1. 네이버 카페 게시글에서 확장 아이콘을 누른다.
2. 검색 범위를 고르고 목록의 **재생**을 누른다.
3. 열린 SOOP 탭에서 **재생**을 누른다. 광고가 재생 중이면 본편이 준비될 때까지 기다린다.
4. **이전/다음**으로 항목을 수동 전환한다.

지원 구간 표기는 `03:23 ~ 04:00`, `01:03:23 ~ 01:04:00`이다. 링크의 `change_second`는 종료 시각 없는 시작점으로 처리한다.

현재 MVP는 카페 본문 또는 현재 로드된 댓글 안의 SOOP URL을 입력으로 삼는다. 시간 범위는 같은 본문 컴포넌트나 같은 댓글에 작성하며, 구간 종료 후 다음 항목은 사용자가 선택한다.

## 확인
