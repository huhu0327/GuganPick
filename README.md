# SOOP 구간 재생 확장 프로그램

## 설치

1. Chrome에서 `chrome://extensions`를 연다.
2. **개발자 모드**를 켠다.
3. **압축해제된 확장 프로그램을 로드합니다**에서 이 `01_src` 폴더를 선택한다.

## 사용

1. 네이버 카페 게시글에서 확장 아이콘을 누른다.
2. 재생 옵션을 고르고 **현재 페이지 패널 열기**를 누른다.
3. 목록의 **재생**을 누른다.
4. 열린 SOOP 탭에서 **재생**을 누른다. 광고가 재생 중이면 본편이 준비될 때까지 기다린다.

**첫 구간 자동 재생**은 기본으로 꺼져 있다. **구간마다 멈추기**를 켜면 선택한 구간 종료점에서 멈추고 다음 유효 구간이 있으면 재생 확인 팝업을 표시한다. 이 옵션이 꺼져 있고 기본으로 켜진 **마지막 구간 멈추기**를 사용하면 목록의 마지막 구간 종료점까지 계속 재생한 뒤 멈춘다. 둘 다 끄면 계속 재생한다. 게시자가 별도 댓글로 `[봤]`을 쓰면 현재 영상의 구간 목록 전체가 하나의 `- 봤 -` 오버레이로 덮여 재생할 수 없다.

일반 VOD와 Catch의 SOOP 구간 패널에는 현재 영상 게시자가 직접 작성한 SOOP 댓글의 시간 구간만 표시한다. 게시자 댓글에 시간 구간이 없으면 빈 목록으로 표시한다.

지원 구간 표기는 `(제목) [03:23] ~ [04:00]`, `[01:03:23] ~ [01:04:00]`이다. 제목은 생략할 수 있다. 링크의 `change_second`와 `start`는 종료 시각 없는 시작점으로 처리한다.

현재 MVP는 카페 본문 또는 현재 로드된 댓글 안의 SOOP URL을 입력으로 삼는다. 시간 범위는 같은 본문 컴포넌트나 같은 댓글에 작성한다.
