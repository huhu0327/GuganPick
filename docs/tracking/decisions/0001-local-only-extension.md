# 서버 없이 브라우저 안에서만 처리

## 배경

제보자는 기존 네이버 카페와 SOOP을 그대로 사용하고, 스트리머만 확장을 설치한다. 수집 대상에는 카페 본문·댓글과 작성자 표시명이 포함되어 별도 서버로 보내면 운영·보안 범위가 크게 늘어난다.

## 결정

영상 목록, 출처, 작성자, 활성 항목, 재생 옵션은 Chrome 로컬 저장소에만 보관한다. 확장은 별도 계정, 서버, 데이터베이스, 원격 분석 기능을 사용하지 않는다.

## 검토한 대안

- 서버 계정과 데이터베이스: 여러 기기 동기화는 가능하지만 카페 데이터 전송, 인증, 보관·삭제 정책과 서버 운영이 필요해 현재 단일 스트리머 도구의 범위를 넘는다.
- 카페 글에 모든 상태 저장: 별도 저장소는 없지만 재생 상태와 개인 옵션을 공개 글에 섞게 되고 페이지 편집 권한에도 의존한다.

## 결과

카페 데이터가 확장 밖으로 나가지 않고 설치가 단순하다. 대신 여러 브라우저 간 목록·옵션 동기화와 원격 운영 관리는 제공할 수 없다. 외부 동기화를 추가하려면 데이터 범위와 동의·삭제 정책을 먼저 새로 결정해야 한다.
