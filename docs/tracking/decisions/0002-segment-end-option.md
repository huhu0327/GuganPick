# 구간 종료 시 멈춤을 선택 옵션으로 제공

## 배경

지정 구간만 확인하려는 상황에는 종료점 일시정지가 유용하지만, 영상의 나머지를 계속 보려는 상황에서는 강제 정지가 흐름을 끊는다. 두 사용 방식이 모두 필요하며 사용자가 기본적으로 개입하지 않아도 영상이 이어져야 한다.

## 결정

구간 종료 시 멈춤을 켜고 끌 수 있게 하고 기본값은 꺼짐으로 한다. 꺼짐에서는 같은 영상을 계속 재생하고, 켜짐에서만 종료점에 도달하면 일시정지한다. 어느 상태에서도 다음 항목으로 자동 이동하지 않는다.

## 검토한 대안

- 항상 종료점에서 멈춤: 지정 구간 확인에는 단순하지만 기본 시청 흐름을 매번 중단한다.
- 항상 계속 재생: 기본 시청은 자연스럽지만 지정 구간만 보고 멈추려는 사용자가 직접 시간을 맞춰야 한다.
- 종료 후 다음 항목 자동 재생: 연속 처리는 빠르지만 페이지 로딩·광고·자동재생 제한 때문에 예측하지 못한 탭 이동과 재생이 발생할 수 있다.

## 결과

사용자 옵션 저장과 패널 제어가 추가로 필요하다. 기본 동작은 영상 계속 재생이며, 구간 단위 검토가 필요할 때만 사용자가 멈춤을 켠다. 자동 다음 재생은 이 결정으로 제공하지 않는다.
