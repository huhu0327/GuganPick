# 구간별·마지막 구간 종료 옵션 제공

## 배경

지정 구간만 확인하려는 상황에는 종료점 일시정지가 유용하지만, 영상의 나머지를 계속 보려는 상황에서는 강제 정지가 흐름을 끊는다. 두 사용 방식이 모두 필요하며 사용자가 기본적으로 개입하지 않아도 영상이 이어져야 한다.

## 결정

`구간마다 멈추기`는 기본 켜짐으로 두고, 켜면 사용자가 선택한 구간 종료점에서 멈춘다. 다음 유효 구간이 있으면 확인 팝업을 표시하고 사용자가 선택한 경우에만 재생한다. 이 옵션이 꺼져 있고 기본 켜짐인 `마지막 구간 멈추기`를 사용하면 재생 시작 당시 목록의 마지막 유효 구간 종료점에서 멈춘다. 둘 다 꺼져 있으면 계속 재생하며 다음 항목은 자동 재생하지 않는다.

## 검토한 대안

- 항상 각 종료점에서 멈춤: 지정 구간 확인에는 단순하지만 기본 시청 흐름을 매번 중단한다.
- 항상 계속 재생: 기본 시청은 자연스럽지만 지정 구간만 보고 멈추려는 사용자가 직접 시간을 맞춰야 한다.
- 다른 영상까지 자동 이동: 페이지 로딩·광고·자동재생 제한 때문에 예측하지 못한 이동이 발생할 수 있어 제외한다.

## 결과

기본 동작은 중간 구간을 지나 계속 재생하고 마지막 유효 구간 종료점에서 멈추는 것이다. 구간마다 확인하려는 사용자는 `구간마다 멈추기`를 켤 수 있다. 재생 옵션은 로컬 저장소에 유지한다.
