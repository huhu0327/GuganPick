# 현재 상태

## 구현됨

- Chrome Manifest V3 확장 등록, 네이버 카페·SOOP 콘텐츠 스크립트, 아이콘 클릭 및 탭 이동이 구현되어 있다. 브라우저 통합 자동 검사는 없다.
- 허용 SOOP URL, `change_second`, 분:초·시:분:초 범위, 구간별 중복 키가 구현되어 있다. 2026-09-17에 `node .\test_core.js`가 통과했다.
- 현재 로드된 카페 본문·댓글의 링크 속성, iframe 주소, 링크 카드 데이터, 텍스트 URL 수집과 패널 표시가 구현되어 있다. 실제 카페 레이아웃에 대한 반복 검증은 남아 있다.
- 광고 대기, 본편 탐색, 시작점 이동, 패널이 열린 동안의 종료점 일시정지, 이전·다음 수동 선택이 구현되어 있다. 카페에서 SOOP 탭을 연 뒤에는 SOOP 패널에서 재생을 다시 눌러야 한다. 실제 SOOP VOD·Catch 조합 검증은 남아 있다.
- 목록과 활성 번호를 브라우저 로컬 저장소에 유지한다.

## 남은 작업

1. 구간 종료 시 멈춤 옵션을 추가하고 기본값을 꺼짐으로 저장한다. 꺼짐에서는 종료점을 지나 계속 재생하고, 켜짐에서는 패널 표시 여부와 무관하게 일시정지해야 한다.
2. 네이버 카페의 실제 본문 카드와 현재 댓글 표본에서 검색 범위·작성자·중복 제거를 확인한다.
3. SOOP의 광고 있음·없음, 일반 VOD·Catch, 자동재생 거부, 길이 초과 표본에서 재생 상태를 확인한다.
4. 외부 DOM 변경을 재현 가능한 수동 확인 절차로 축적하고 필요한 최소 자동 검사를 결정한다.

## 차단 요소

구현을 막는 내부 의존성은 없다. 브라우저 통합 완료 판정에는 접근 가능한 네이버 카페 게시글과 SOOP 영상 표본이 필요하다.
