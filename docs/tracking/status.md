# 현재 상태

## 구현됨

- Chrome Manifest V3 확장 등록, 네이버 카페·SOOP 콘텐츠 스크립트, 아이콘 설정 팝업 및 탭 이동이 구현되어 있다. 브라우저 통합 자동 검사는 없다.
- 허용 SOOP URL, `change_second`, 분:초·시:분:초 범위, 구간별 중복 키가 구현되어 있다. 2026-09-17에 `node .\test_core.js`가 통과했다.
- 현재 로드된 카페 본문·댓글의 링크 속성, iframe 주소, 링크 카드 데이터, 텍스트 URL 수집과 패널 표시가 구현되어 있다. 실제 카페 레이아웃에 대한 반복 검증은 남아 있다.
- 광고 대기, 준비된 본편의 즉시 시작점 이동, 종료점 일시정지, 이전·다음 수동 선택, 본편 이벤트 기반 상태 동기화가 구현되어 있다. 카페에서 SOOP 탭을 연 뒤에는 SOOP 패널에서 재생을 다시 눌러야 한다. 실제 SOOP VOD·Catch 조합 검증은 남아 있다.
- 목록, 활성 번호, 검색 범위, 탭·패널·첫 구간 자동 재생·구간마다 멈춤·마지막 구간 멈춤 옵션을 브라우저 로컬 저장소에 유지한다.
- SOOP 패널은 현재 영상 게시자가 작성한 SOOP 댓글 구간만 표시하며, 다른 작성자의 구간을 제외하고 게시자 구간이 없으면 대체 카드 없이 빈 상태를 표시한다.
- `start` URL 시작점, 기본 ON 첫 구간 자동 재생, 기본 ON 구간마다 멈추기, 시작·종료 타임스탬프 재생, 완료 구간 하이라이트 유지가 구현되어 있다.
- `[봤]` 댓글 구간의 오버레이·조작 차단이 구현되어 있다. Catch의 게시자·댓글 DOM과 `#video_p` 본편 선택자는 확인했지만 실제 미디어 재생 흐름 검증은 남아 있다.

## 남은 작업

1. 네이버 카페의 실제 본문 카드와 현재 댓글 표본에서 검색 범위·작성자·중복 제거를 확인한다.
2. SOOP의 광고 있음·없음, 일반 VOD·Catch, 자동재생 거부, 길이 초과, 플레이어 자체 일시정지·재생 표본에서 재생 상태를 확인한다.
3. 외부 DOM 변경을 재현 가능한 수동 확인 절차로 축적하고 필요한 최소 자동 검사를 결정한다.

## 차단 요소

구현을 막는 내부 의존성은 없다. 브라우저 통합 완료 판정에는 접근 가능한 네이버 카페 게시글과 SOOP 영상 표본이 필요하다.
