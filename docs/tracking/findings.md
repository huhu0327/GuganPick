# 해결되지 않은 문제

## 외부 페이지 통합이 검증되지 않음

- 조건과 증상: 네이버 카페 또는 SOOP이 DOM 클래스와 미디어 식별자를 바꾸면 목록이 비거나 본편을 60초 안에 찾지 못할 수 있다.
- 영향: 공용 파서 검사는 통과해도 사용자의 핵심 검색·재생 흐름 전체가 동작하지 않을 수 있다.
- 지금 해결하지 못한 이유: 저장소에 브라우저 DOM 표본이나 통합 검사 환경이 없으며 로그인된 네이버 카페 표본도 포함되어 있지 않다.
- 가능한 접근: 접근 가능한 본문·댓글·VOD·Catch 표본으로 수동 확인표를 실행하고, 반복 실패가 확인된 선택자만 고정 표본 검사로 옮긴다.

## 패널을 닫으면 종료 감시가 해제됨

- 조건과 증상: 종료점이 있는 영상을 재생한 뒤 SOOP 패널을 닫으면 미디어 시간 감시가 제거되어 종료점에서 멈추지 않는다.
- 영향: 구간 종료 시 멈춤을 켠 사용자가 패널을 닫으면 선택한 동작을 얻지 못한다.
- 지금 해결하지 못한 이유: 해결하려면 `content.js`의 UI 수명과 미디어 감시 수명을 분리하고 실제 SOOP에서 검증해야 하며, 해당 코드 변경 작업은 아직 승인·일정화되지 않았다.
- 가능한 접근: 패널을 닫아도 감시를 유지하고, 사용자가 중지를 누르거나 페이지를 이동할 때만 감시를 정리한다.
