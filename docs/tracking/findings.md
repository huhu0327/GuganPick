# 해결되지 않은 문제

## 외부 페이지 통합이 검증되지 않음

- 조건과 증상: 네이버 카페 또는 SOOP이 DOM 클래스와 미디어 식별자를 바꾸면 목록이 비거나 본편을 60초 안에 찾지 못할 수 있다.
- 영향: 공용 파서 검사는 통과해도 사용자의 핵심 검색·재생 흐름 전체가 동작하지 않을 수 있다.
- 지금 해결하지 못한 이유: 저장소에 브라우저 DOM 표본이나 통합 검사 환경이 없으며 로그인된 네이버 카페 표본도 포함되어 있지 않다.
- 가능한 접근: 접근 가능한 본문·댓글·VOD·Catch 표본으로 수동 확인표를 실행하고, 반복 실패가 확인된 선택자만 고정 표본 검사로 옮긴다.

## 브라우저 통합 검증 필요

- 설정 팝업의 정적 검사와 재생 정책 단위 검사는 통과했다.
- SOOP `207390601`의 실제 DOM에서 `[id^="txtComment"]` 댓글 1개와 `(테스트) [ 00:01 ] ~ [ 00:10 ]`, 작성자 `a후후 (ndr0271)` 추출은 확인했다.
- 현재 작업 환경에는 Chrome 자동화 세션이 없어 확장을 다시 로드한 뒤 댓글 구간이 패널에 표시되고 재생되는 흐름은 직접 확인하지 못했다.
- 구간 번호·행별 재생 버튼·현재 재생 시각 하이라이트도 Chrome에서 직접 확인해야 한다.
- 실제 확장 팝업 크기, 패널 열기, 패널을 닫은 뒤 종료 감시, 다음 영상 이동은 Chrome에 확장을 다시 로드한 뒤 확인해야 한다.
