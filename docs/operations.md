# 실행과 검증

## 준비물

- 데스크톱 Chrome
- 공용 로직 검사용 Node.js
- 이 디렉터리 전체 파일

별도 패키지 설치, 환경 변수, 데이터 초기화, 빌드는 없다.

## 공용 로직 검사

프로젝트 디렉터리에서 다음 명령을 실행한다.

```powershell
node .\test_core.js
```

성공 기준은 종료 코드 0과 `core tests passed` 출력이다. 이 검사는 브라우저 DOM이나 실제 영상 재생을 검증하지 않는다.

## Chrome 설치

1. Chrome에서 `chrome://extensions`를 연다.
2. 개발자 모드를 켠다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 프로젝트 디렉터리를 선택한다.
4. 코드 변경 후 확장 카드의 새로고침 버튼을 누르고 대상 카페·SOOP 페이지도 새로 고친다.

## 수동 확인

1. 허용된 SOOP 링크와 시간 범위가 같은 영역에 있는 네이버 카페 게시글을 연다.
2. 확장 아이콘을 눌러 본문, 현재 댓글, 본문+현재 댓글 검색 결과를 각각 확인한다.
3. 재생을 눌러 SOOP 탭이 열리고 광고가 본편 시간으로 계산되지 않는지 확인한다.
4. 시작점 이동, 자동재생 거부 안내, 영상 길이 초과 오류를 확인한다.
5. 구간 종료 옵션이 구현된 뒤에는 기본 꺼짐에서 연속 재생, 켜짐에서 종료점 일시정지를 각각 확인한다.

## 배포

현재 배포 파이프라인이나 스토어 패키징은 없다. 사용자에게 전달하는 설치 폴더에는 `manifest.json`과 세 JavaScript 파일을 같은 디렉터리 구조로 포함해야 한다.
