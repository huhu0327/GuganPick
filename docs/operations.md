# 실행과 검증

## 준비물

- 데스크톱 Chrome
- 공용 로직 검사용 Node.js
- 이 디렉터리 전체 파일

별도 패키지 설치, 환경 변수, 데이터 초기화, 빌드는 없다.

## 공용 로직 검사

프로젝트 디렉터리에서 다음 명령을 실행한다.

```powershell
node .\test_core.js
node .\test_settings.js
```

성공 기준은 두 명령의 종료 코드 0과 `core tests passed`, `settings tests passed` 출력이다. 이 검사는 브라우저 DOM이나 실제 영상 재생을 검증하지 않는다.

## Chrome 설치

1. Chrome에서 `chrome://extensions`를 연다.
2. 개발자 모드를 켠다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 프로젝트 디렉터리를 선택한다.
4. 코드 변경 후 확장 카드의 새로고침 버튼을 누르고 대상 카페·SOOP 페이지도 새로 고친다.

## 수동 확인

1. 허용된 SOOP 링크와 시간 범위가 같은 영역에 있는 네이버 카페 게시글을 연다.
2. 확장 아이콘을 눌러 본문, 현재 댓글, 본문+현재 댓글 검색 결과를 각각 확인한다.
3. 재생을 눌러 SOOP 탭이 열리고 광고가 본편 시간으로 계산되지 않는지 확인한다.
4. 시작점 이동, 자동재생 거부 안내, 영상 길이 초과 오류를 확인한다.
5. 옵션 팝업에서 `구간 자동 넘기기`와 `기본 검색 범위`가 없고 `첫 구간 자동 재생`·`구간마다 멈추기`·`마지막 구간 멈추기`가 기본 켜짐인지 확인한다. 일반 VOD와 Catch의 두 구간 표본에서 구간마다 멈추기를 켰을 때 첫 구간 종료 후 다음 구간 확인 팝업이 표시되는지 확인하고, 마지막 구간 정지와 계속 재생 조합도 각각 확인한다.
6. SOOP 영상 게시자의 댓글에 시간 구간이 있으면 해당 구간만 표시하고, 다른 작성자 댓글의 구간은 제외하며, 게시자 댓글에 구간이 없으면 빈 카드 없이 빈 상태만 표시하는지 확인한다.
7. 광고가 없고 본편이 준비된 상태에서 패널 재생이 즉시 시작되는지, 광고 중에는 본편을 기다리는지 확인한다.
8. 패널 버튼과 SOOP 플레이어 자체 버튼으로 각각 일시정지·재생했을 때 활성 카드 상태와 패널 버튼명이 함께 바뀌는지 확인한다.
9. `?start=7` 링크가 7초 시작점으로 수집되는지, 시작·종료 타임스탬프가 각각 해당 초를 재생하는지 확인한다.
10. 첫 구간 자동 재생을 켜면 첫 유효 구간이 한 번만 자동 시작되고, 구간 완료 후 다음 항목 선택 전까지 해당 카드의 하이라이트와 `완료` 표시가 유지되는지 확인한다.
11. 게시자가 별도 댓글로 `[봤]`을 추가하면 구간 목록 전체가 반투명 검정 오버레이 하나로 덮이고 중앙에 `- 봤 -`이 한 번만 표시되며 모든 클릭이 막히는지 확인한다.
12. 일반 VOD와 `https://vod.sooplive.com/player/207752565/catch`에서 게시자 댓글 수집과 본편 선택자가 각각 동작하는지 확인한다.

## 배포

현재 배포 파이프라인이나 스토어 패키징은 없다. 사용자에게 전달하는 설치 폴더에는 `manifest.json`과 세 JavaScript 파일을 같은 디렉터리 구조로 포함해야 한다.
