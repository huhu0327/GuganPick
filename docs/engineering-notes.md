# 개발 메모

## 카페 링크가 보이는데 수집되지 않음

- 증상: 게시글 화면에 SOOP 카드가 보이지만 목록이 비어 있다.
- 원인: 네이버 카페 본문은 별도 프레임에 있고, 링크 카드는 일반 텍스트가 아니라 `href`, `data-linkdata`, iframe `src` 중 하나에 원본 주소를 둘 수 있다. 댓글은 사용자가 펼친 분량만 DOM에 존재한다.
- 대응: 콘텐츠 스크립트의 프레임 실행 설정을 유지하고, 실제 본문 프레임에서 링크 속성·카드 데이터·텍스트 노드를 각각 확인한다. 수정 후 본문 카드와 현재 댓글을 따로 검색해 검증한다.

## 같은 영상이 두 번 나타남

- 증상: 카드 하나가 썸네일과 제목 링크 때문에 중복 항목으로 보이거나, 반대로 서로 다른 구간이 하나로 사라진다.
- 원인: 네이버 링크 카드의 여러 요소가 같은 URL을 가리킨다. 영상 번호만으로 합치면 같은 영상의 다른 구간도 손실된다.
- 대응: 영상 식별자·시작·종료의 조합으로만 중복 제거한다. 같은 카드 중복 1개와 같은 영상의 서로 다른 구간 2개를 함께 확인한다.

## 광고 뒤에 시작 위치가 적용되지 않음

- 증상: 광고 시간이 구간 시작으로 오인되거나 본편이 준비되기 전에 재생 위치 변경이 실패한다.
- 원인: SOOP은 광고용 `#adVideo`와 본편 `#video`를 별도로 사용하며 준비 시점이 다르다.
- 대응: 재생 중인 광고가 끝날 때까지 기다린 뒤 본편의 메타데이터가 준비된 상태에서 위치를 설정한다. 광고 재생, 광고 없는 재생, 60초 안에 본편이 나타나지 않는 경우를 각각 확인한다.

## 종료 시각이 정확히 일치하지 않음

- 증상: 종료 옵션을 켰을 때 표시한 종료 시각보다 조금 늦게 멈춘다.
- 원인: `timeupdate`는 프레임 단위 이벤트가 아니며 브라우저 부하와 버퍼링에 따라 호출 간격이 달라진다.
- 대응: 이 기능을 편집 정확도로 표현하지 않는다. 허용 오차가 제품 요구가 되면 실제 브라우저 표본으로 측정한 뒤 더 촘촘한 감시 방식과 성능 비용을 함께 결정한다.

## 자동 재생이 시작되지 않음

- 증상: 시작 위치는 설정됐지만 영상이 일시정지 상태로 남는다.
- 원인: 브라우저의 사용자 동작 정책이 `video.play()`를 거부할 수 있다.
- 대응: 오류를 숨기거나 반복 호출하지 말고 SOOP 재생 버튼을 누른 뒤 다시 시도하라고 안내한다. 사용자 조작 뒤 재시도와 상태 문구를 확인한다.
