# 사용 계약

## 확장 아이콘

- 입력: 사용자가 네이버 카페 또는 허용된 SOOP VOD 탭에서 확장 아이콘을 누른다.
- 출력: 해당 페이지 위에 목록 패널을 열거나 이미 열린 패널을 닫는다.
- 오류: 카페의 대상 본문·댓글 구조를 찾지 못하면 패널을 만들지 않는다. 허용되지 않은 사이트에서는 콘텐츠 스크립트가 없어 동작하지 않는다.

## 카페 검색

- 입력: 사용자가 `본문`, `현재 댓글`, `본문 + 현재 댓글` 중 범위를 선택하고 검색한다. 후보는 일반 링크, iframe 주소, 링크 카드 데이터, 텍스트 URL이다.
- 출력: 제목, 시간, 출처, 작성자, 상태가 있는 중복 제거 목록을 표시하고 브라우저 로컬 저장소에 보관한다.
- 오류: 유효한 SOOP URL이 없으면 빈 결과를 표시한다. 시간 범위 모양은 있으나 값이 잘못됐거나 시작이 종료보다 늦으면 해당 항목을 오류로 표시하고 재생하지 않는다.

## 허용 URL

- 입력 형식: `http` 또는 `https`의 `vod.sooplive.com/player/{숫자}`, `vod.sooplive.co.kr/player/{숫자}`, 선택적인 `/catch`, 선택적인 `change_second={0 이상의 숫자}`.
- 출력: 정규화된 URL, 영상 식별자, 선택적인 시작 초를 만든다.
- 오류: HTTP·HTTPS 이외 프로토콜, 유사 도메인, 숫자가 아닌 영상 번호, 다른 경로는 거부한다. 유효하지 않은 `change_second`는 URL 자체를 거부하지 않고 시작점 없음으로 처리한다. HTTP 주소를 열었을 때 SOOP이 HTTPS로 전환하지 않으면 콘텐츠 스크립트가 실행되지 않아 패널과 재생 제어를 제공할 수 없다.

## 시간 범위

- 입력 형식: `03:23 ~ 04:00` 또는 `01:03:23 ~ 01:04:00`. 2단 형식의 첫 값과 3단 형식의 시는 1~3자리이며, 나머지는 2자리다. 구분자는 `~`, 전각 물결표, 여러 대시 문자를 허용한다.
- 출력: 시작·종료 초를 만든다.
- 오류: 2단 형식의 초 또는 3단 형식의 분·초가 59를 넘거나 시작이 종료 이상이면 유효한 범위를 만들지 않는다. 지원하는 모양과 일치하지 않는 텍스트는 오류 범위가 아니라 구간 없음으로 처리한다.

## 재생 조작

- 입력: 카페 목록의 재생, SOOP 목록의 재생·이전·다음·일시정지·중지와 구간 종료 시 멈춤 옵션.
- 출력: 카페에서 다른 영상을 선택하면 검증된 SOOP 탭과 목록 패널을 연다. 사용자가 열린 SOOP 패널에서 재생을 다시 누르면 본편 시작 위치를 바꿔 재생한다. 종료 옵션이 켜진 범위는 종료점에서 일시정지하며 기본 꺼짐에서는 계속 재생한다. 패널을 닫아도 저장된 옵션 값은 유지한다.
- 오류: 본편을 60초 안에 찾지 못함, 영상 길이 초과, 자동재생 거부는 항목 상태와 설명으로 표시한다. 광고 미디어에는 시작·종료 조작을 적용하지 않는다.
