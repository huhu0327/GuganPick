# 사용 계약

## 확장 아이콘

- 입력: 사용자가 네이버 카페 또는 허용된 SOOP VOD 탭에서 확장 아이콘을 누른다.
- 출력: 해당 페이지 위에 목록 패널을 열거나 이미 열린 패널을 닫는다.
- 오류: 카페의 대상 본문·댓글 구조를 찾지 못하면 패널을 만들지 않는다. 허용되지 않은 사이트에서는 콘텐츠 스크립트가 없어 동작하지 않는다.

## 카페 검색

- 입력: 사용자가 `본문`, `현재 댓글`, `본문 + 현재 댓글` 중 범위를 선택하고 검색한다. 후보는 일반 링크, iframe 주소, 링크 카드 데이터, 텍스트 URL이다.
- 출력: 제목, 시간, 출처, 작성자, 상태가 있는 중복 제거 목록을 표시하고 브라우저 로컬 저장소에 보관한다.
- 오류: 유효한 SOOP URL이 없으면 빈 결과를 표시한다. 시간 범위 모양은 있으나 값이 잘못됐거나 시작이 종료보다 늦으면 해당 항목을 오류로 표시하고 재생하지 않는다.

## SOOP 댓글 검색

- 입력: 사용자가 허용된 SOOP 일반 VOD 또는 Catch 페이지에서 패널을 열면 현재 영상 게시자와 작성자가 같은 댓글에서 `(제목) [ 00:01 ] ~ [ 00:10 ]` 형식의 시간 범위를 모두 검색한다. 양쪽 계정 ID가 있으면 ID를 우선 비교하고, 한쪽 ID가 없으면 공백을 정규화한 표시 닉네임을 대소문자 구분 없이 비교한다. 댓글 작성자 `a후후 (ndr0271)`은 게시자 `a후후`와 같은 작성자로 판정한다. 한 댓글에 여러 범위가 있으면 작성 순서대로 전부 읽는다. 게시자의 댓글 중 하나에 정확한 표식 `[봤]`이 있으면 별도 댓글이어도 현재 영상의 게시자 구간 전체를 본 구간으로 처리한다.
- 출력: 게시자 댓글의 각 범위를 현재 VOD URL과 결합해 `SOOP 댓글` 출처와 작성자가 있는 별도 구간 항목으로 저장한다. 다른 작성자나 식별할 수 없는 작성자의 댓글은 저장하거나 표시하지 않는다. 정렬 순서는 댓글 DOM 순서, 같은 댓글 안에서는 작성 순서다. 한 댓글에 `(테스트1) [ 00:01 ] ~ [ 00:10 ]`과 `(테스트2) [ 00:11 ] ~ [ 00:20 ]`이 있으면 패널에 `1. 테스트1 (00:01) ~ (00:10)`, `2. 테스트2 (00:11) ~ (00:20)` 두 항목을 표시한다. 같은 영상·시작·종료 조합은 SOOP 댓글 항목끼리 중복 제거하며 기존 댓글 항목이 있으면 기존 상태·제목·작성자를 유지한다. 첫 댓글 구간을 현재 항목으로 선택한다.
- 새로고침: 페이지 새로고침 직후 댓글 DOM이 비어 있거나 로딩 중이면 현재 게시자와 다시 일치하는 저장 구간만 표시한다. 댓글 영역의 로딩 완료 또는 변경이 확인되면 현재 VOD의 게시자 댓글 구간만 다시 검색해 저장값과 재조정한다. 동일 구간은 상태와 현재 선택을 유지하고, 선택 구간이 사라졌으면 첫 구간을 선택한다. 댓글 로딩 완료 후 게시자 댓글에 시간 범위 후보가 없으면 기존 댓글 구간을 제거하고 빈 상태를 표시하며 대체 항목을 만들지 않는다.
- 오류: 지원하는 시간 범위 모양이지만 값이 잘못됐거나 시작이 종료 이상이면 해당 범위만 오류 항목으로 표시하고 재생하지 않으며, 같은 댓글의 다른 유효 범위는 유지한다. 아직 로드되지 않은 댓글은 댓글 영역이 변경될 때 재검색한다.

## 허용 URL

- 입력 형식: `http` 또는 `https`의 `vod.sooplive.com/player/{숫자}`, `vod.sooplive.co.kr/player/{숫자}`, 선택적인 `/catch`, 선택적인 `change_second={0 이상의 숫자}` 또는 `start={0 이상의 숫자}`. 두 시작 쿼리가 함께 있으면 `change_second`를 우선한다.
- 출력: 정규화된 URL, 영상 식별자, 선택적인 시작 초를 만든다.
- 오류: HTTP·HTTPS 이외 프로토콜, 유사 도메인, 숫자가 아닌 영상 번호, 다른 경로는 거부한다. 유효하지 않은 `change_second`는 URL 자체를 거부하지 않고 시작점 없음으로 처리한다. HTTP 주소를 열었을 때 SOOP이 HTTPS로 전환하지 않으면 콘텐츠 스크립트가 실행되지 않아 패널과 재생 제어를 제공할 수 없다.

## 시간 범위

- 입력 형식: 본문·댓글에는 선택적인 제목과 대괄호로 감싼 시간 범위를 `(제목) [ 00:01 ] ~ [ 00:10 ]` 형식으로 작성한다. 제목이 없으면 `[ 00:01 ] ~ [ 00:10 ]`만 작성한다. 시간은 `[ 03:23 ] ~ [ 04:00 ]` 또는 `[ 01:03:23 ] ~ [ 01:04:00 ]` 형식을 사용하며, 2단 형식의 첫 값과 3단 형식의 시는 1~3자리이고 나머지는 2자리다. 한 문자열에 여러 범위가 있으면 왼쪽부터 각각 읽는다.
- 출력: 발견 순서대로 하나 이상의 선택적인 제목과 시작·종료 초를 만든다.
- 오류: 2단 형식의 초 또는 3단 형식의 분·초가 59를 넘거나 시작이 종료 이상이면 해당 범위만 유효한 범위로 만들지 않고 같은 문자열의 다른 유효 범위는 유지한다. 지원하는 모양과 일치하지 않는 텍스트는 오류 범위가 아니라 구간 없음으로 처리한다.

## SOOP 구간 재생 패널 정보

- 입력: 허용된 SOOP VOD 페이지에서 현재 영상 게시자가 작성한 SOOP 댓글에서 찾은 중복 제거 구간 목록과 본편 미디어의 현재 재생 시각.
- 출력: 유효한 구간을 댓글 발견 순서대로 한 행씩 표시하고 첫 구간부터 `1`로 시작하는 연속 번호를 붙인다. 댓글의 `(테스트) [ 00:01 ] ~ [ 00:10 ]`은 첫 줄에 `1. 테스트`, 둘째 줄에 직접 누를 수 있는 시작·종료 타임스탬프로 표시한다. 각 타임스탬프를 누르면 해당 초부터 본편 재생을 요청한다. 제목이 없으면 첫 줄에는 번호만 표시한다. SOOP 댓글 출처와 작성자는 표시하지 않으며, 각 행 맨 오른쪽에는 해당 구간의 `재생` 버튼을 둔다. `[봤]`이면 구간별 오버레이 대신 구간 목록 전체를 반투명 검정 오버레이 하나로 덮고 중앙에 `- 봤 -`을 한 번만 표시하며 목록의 모든 클릭을 막는다. 상단 바와 첫 행 사이에는 `12px` 여백을 둔다. 댓글 시간 구간이 없으면 카드 없이 `발견한 SOOP 구간이 없습니다.`를 표시하며 SOOP 패널 하단 안내 푸터는 표시하지 않는다.
- 하이라이트와 상태: 본편의 현재 재생 시각이 `시작 시각 이상, 종료 시각 미만`인 구간 행 하나를 하이라이트하고 해당 행에만 재생 상태를 표시한다. 선택 구간이 종료 시각에 도달해 완료되면 다음 구간을 선택하기 전까지 해당 행의 하이라이트와 `완료` 표시를 유지한다. 비활성 행에 저장된 과거 재생 상태는 화면에서 숨긴다. 겹치는 구간이 있으면 사용자가 마지막으로 선택한 구간을 우선하고, 선택 구간이 없으면 번호가 가장 작은 구간을 하이라이트한다. 일시정지 중에도 현재 시각이 구간 안이면 하이라이트와 상태를 유지하며, 광고 재생 중이거나 어느 구간에도 속하지 않고 완료 선택도 없으면 모든 하이라이트와 정상 상태를 숨긴다.
- 오류: 잘못된 구간은 연속 번호에 포함하지 않고 오류 상태로 표시하며 `재생` 버튼을 비활성화한다. 다른 영상을 열면 이전 영상의 구간 행과 하이라이트를 남기지 않는다.

## 재생 조작

- 입력: 카페 목록의 재생, SOOP 목록의 재생·타임스탬프·이전·다음·일시정지/이어서 재생과 `첫 구간 자동 재생`·`구간마다 멈추기`·`마지막 구간 멈추기` 옵션. 첫 구간 자동 재생과 구간마다 멈추기는 기본 켜짐이고 마지막 구간 멈추기도 기본 켜짐이다.
- 출력: 카페에서 다른 영상을 선택하면 검증된 SOOP 탭과 목록 패널을 연다. SOOP 패널에서 구간 행의 `재생` 또는 타임스탬프를 누르면 해당 행을 현재 구간으로 선택한다. 첫 구간 자동 재생이 켜져 있으면 현재 영상의 첫 재생 가능한 댓글 구간을 페이지당 한 번 자동 선택해 재생한다. 일반 VOD는 `video#video`, Catch는 `video#video_p`만 본편으로 사용한다. 광고가 없고 본편과 선택 구간을 수용하는 영상 길이가 준비됐으면 고정 폴링 주기를 기다리지 않고 선택 시각부터 재생하며, 광고 중이거나 본편 또는 길이가 준비되지 않았으면 기존 대기 경로를 사용한다. `일시정지`와 `이어서 재생` 버튼 및 활성 구간 상태는 실제 본편의 재생·일시정지 이벤트를 반영하며 SOOP 플레이어 자체 조작에도 동일하게 갱신된다. 구간마다 멈추기가 켜져 있으면 선택 구간 종료점에서 멈추고 다음 유효 구간이 있을 때 `재생`·`취소` 확인 팝업을 표시한다. 이 옵션이 꺼져 있고 마지막 구간 멈추기가 켜져 있으면 재생 시작 당시 목록의 마지막 유효 구간 종료점에서 멈춘다. 두 옵션이 모두 꺼져 있으면 계속 재생한다. 사용자가 확인 팝업에서 직접 선택하지 않으면 다음 구간이나 다음 영상을 자동 재생하지 않는다.
- 오류: 해당 페이지 유형의 본편을 60초 안에 찾지 못하면 본편 준비 오류를 표시한다. 새로고침 직후 `duration`이 `0`, `0.x`, `NaN`이거나 선택 구간보다 짧게 보고되는 동안에는 길이 초과로 확정하지 않고 최대 60초까지 길이 갱신을 기다린다. 그 뒤에도 선택 구간을 수용하지 못하는 실제 길이면 영상 길이 초과 오류를 표시한다. 자동재생 거부도 항목 상태와 설명으로 표시한다. 광고 미디어에는 시작·종료 조작을 적용하지 않는다.
