# 사용 계약

## 확장 아이콘

- 입력: 사용자가 네이버 카페 또는 허용된 SOOP VOD 탭에서 확장 아이콘을 누른다.
- 출력: 해당 페이지 위에 목록 패널을 열거나 이미 열린 패널을 닫는다.
- 오류: 카페의 대상 본문·댓글 구조를 찾지 못하면 패널을 만들지 않는다. 허용되지 않은 사이트에서는 콘텐츠 스크립트가 없어 동작하지 않는다.

## 카페 검색

- 입력: 사용자가 `본문`, `현재 댓글`, `본문 + 현재 댓글` 중 범위를 선택하고 검색한다. 후보는 일반 링크, iframe 주소, 링크 카드 데이터, 텍스트 URL이다.
- 출력: 제목, 시간, 출처, 작성자, 상태가 있는 중복 제거 목록을 표시하고 브라우저 로컬 저장소에 보관한다.
- 오류: 유효한 SOOP URL이 없으면 빈 결과를 표시한다. 시간 범위 모양은 있으나 값이 잘못됐거나 시작이 종료보다 늦으면 해당 항목을 오류로 표시하고 재생하지 않는다.

## SOOP 댓글 검색

- 입력: 사용자가 허용된 SOOP VOD 페이지에서 패널을 열면 현재 DOM에 로드된 각 댓글에서 `(제목) [ 00:01 ] ~ [ 00:10 ]` 형식의 시간 범위를 모두 검색한다. 한 댓글에 줄바꿈 또는 일반 텍스트로 여러 범위가 있으면 댓글 안의 작성 순서대로 전부 읽는다.
- 출력: 각 범위를 현재 VOD URL과 결합해 `SOOP 댓글` 출처와 작성자가 있는 별도 구간 항목으로 저장한다. 정렬 순서는 댓글 DOM 순서, 같은 댓글 안에서는 작성 순서다. 한 댓글에 `(테스트1) [ 00:01 ] ~ [ 00:10 ]`과 `(테스트2) [ 00:11 ] ~ [ 00:20 ]`이 있으면 패널에 `1. 테스트1 (00:01) ~ (00:10)`, `2. 테스트2 (00:11) ~ (00:20)` 두 항목을 표시한다. 같은 영상·시작·종료 조합은 항목별로 중복 제거하며 기존 항목이 있으면 기존 제목·출처·작성자를 유지한다. 첫 댓글 구간을 현재 항목으로 선택하고, 댓글 구간이 하나 이상이면 구간 없는 `현재 SOOP 페이지` 대체 항목은 제거한다.
- 새로고침: 페이지 새로고침 직후 댓글 DOM이 비어 있거나 로딩 중이면 저장된 현재 VOD 구간을 즉시 표시하고 삭제하거나 대체 항목으로 교체하지 않는다. 댓글 영역의 로딩 완료 또는 변경이 확인되면 현재 VOD의 댓글 구간만 다시 검색해 저장값과 재조정한다. 동일 구간은 상태와 현재 선택을 유지하고, 선택 구간이 사라졌으면 첫 구간을 선택한다. 댓글 로딩 완료 후 시간 범위 후보가 없다고 확인된 경우에만 기존 댓글 구간을 제거하고 `현재 SOOP 페이지` 대체 항목을 표시한다.
- 오류: 지원하는 시간 범위 모양이지만 값이 잘못됐거나 시작이 종료 이상이면 해당 범위만 오류 항목으로 표시하고 재생하지 않으며, 같은 댓글의 다른 유효 범위는 유지한다. 아직 로드되지 않은 댓글은 댓글 영역이 변경될 때 재검색한다.

## 허용 URL

- 입력 형식: `http` 또는 `https`의 `vod.sooplive.com/player/{숫자}`, `vod.sooplive.co.kr/player/{숫자}`, 선택적인 `/catch`, 선택적인 `change_second={0 이상의 숫자}`.
- 출력: 정규화된 URL, 영상 식별자, 선택적인 시작 초를 만든다.
- 오류: HTTP·HTTPS 이외 프로토콜, 유사 도메인, 숫자가 아닌 영상 번호, 다른 경로는 거부한다. 유효하지 않은 `change_second`는 URL 자체를 거부하지 않고 시작점 없음으로 처리한다. HTTP 주소를 열었을 때 SOOP이 HTTPS로 전환하지 않으면 콘텐츠 스크립트가 실행되지 않아 패널과 재생 제어를 제공할 수 없다.

## 시간 범위

- 입력 형식: 본문·댓글에는 선택적인 제목과 대괄호로 감싼 시간 범위를 `(제목) [ 00:01 ] ~ [ 00:10 ]` 형식으로 작성한다. 제목이 없으면 `[ 00:01 ] ~ [ 00:10 ]`만 작성한다. 시간은 `[ 03:23 ] ~ [ 04:00 ]` 또는 `[ 01:03:23 ] ~ [ 01:04:00 ]` 형식을 사용하며, 2단 형식의 첫 값과 3단 형식의 시는 1~3자리이고 나머지는 2자리다. 한 문자열에 여러 범위가 있으면 왼쪽부터 각각 읽는다.
- 출력: 발견 순서대로 하나 이상의 선택적인 제목과 시작·종료 초를 만든다.
- 오류: 2단 형식의 초 또는 3단 형식의 분·초가 59를 넘거나 시작이 종료 이상이면 해당 범위만 유효한 범위로 만들지 않고 같은 문자열의 다른 유효 범위는 유지한다. 지원하는 모양과 일치하지 않는 텍스트는 오류 범위가 아니라 구간 없음으로 처리한다.

## SOOP 구간 재생 패널 정보

- 입력: 허용된 SOOP VOD 페이지에서 현재 영상에 연결된 중복 제거 구간 목록과 본편 미디어의 현재 재생 시각.
- 출력: 유효한 구간을 댓글 발견 순서대로 한 행씩 표시하고 첫 구간부터 `1`로 시작하는 연속 번호를 붙인다. 댓글의 `(테스트) [ 00:01 ] ~ [ 00:10 ]`은 패널에서 `1. 테스트 (00:01) ~ (00:10)`으로 표시하며, 제목이 없으면 `1. (00:01) ~ (00:10)`으로 표시한다. 각 행 맨 오른쪽에는 해당 구간의 `재생` 버튼을 둔다.
- 하이라이트: 본편의 현재 재생 시각이 `시작 시각 이상, 종료 시각 미만`인 구간 행 하나만 하이라이트한다. 겹치는 구간이 있으면 사용자가 마지막으로 선택한 구간을 우선하고, 선택 구간이 없으면 번호가 가장 작은 구간을 하이라이트한다. 일시정지 중에도 현재 시각이 구간 안이면 하이라이트를 유지하며, 광고 재생 중이거나 어느 구간에도 속하지 않으면 모든 하이라이트를 해제한다.
- 오류: 잘못된 구간은 연속 번호에 포함하지 않고 오류 상태로 표시하며 `재생` 버튼을 비활성화한다. 다른 영상을 열면 이전 영상의 구간 행과 하이라이트를 남기지 않는다.

## 재생 조작

- 입력: 카페 목록의 재생, SOOP 목록의 재생·이전·다음·일시정지/이어서 재생과 자동 넘기기·구간 종료 시 멈춤 옵션. 중지 버튼은 제공하지 않는다.
- 출력: 카페에서 다른 영상을 선택하면 검증된 SOOP 탭과 목록 패널을 연다. SOOP 패널에서 구간 행의 `재생`을 누르면 해당 행을 현재 구간으로 선택하고 본편을 그 구간의 시작 시각부터 재생한다. `일시정지`를 누르면 현재 영상을 일시정지하고 버튼명을 즉시 `이어서 재생`으로 바꾼다. `이어서 재생`을 누르면 일시정지된 위치부터 재생하고, 재생이 시작되면 버튼명을 `일시정지`로 바꾼다. 자동 넘기기가 켜지면 종료점에서 다음 항목을 재생하고 마지막 항목에서 멈춘다. 자동 넘기기가 꺼진 경우 종료 옵션이 켜진 범위만 종료점에서 일시정지하며 기본 꺼짐에서는 계속 재생한다. 패널을 닫아도 저장된 옵션과 종료 감시는 유지한다.
- 오류: 본편을 60초 안에 찾지 못함, 영상 길이 초과, 자동재생 거부는 항목 상태와 설명으로 표시한다. 광고 미디어에는 시작·종료 조작을 적용하지 않는다.
