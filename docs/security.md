# 보안 정책

## 보호 대상

카페 본문·댓글 내용, 댓글 작성자 표시명, 수집한 SOOP URL, 선택한 항목과 재생 상태는 사용자의 탐색 기록에서 파생된 데이터다. 이 데이터는 `chrome.storage.local`에만 저장하며 외부 서버, 분석 도구, 원격 로그로 전송하지 않는다.

## 접근 규칙

| 주체 | 동작 | 허용 조건 | 명시적으로 금지 |
|---|---|---|---|
| 사용자 | 카페 항목 검색 | 사용자가 허용된 카페 페이지에서 확장 패널을 열고 검색 | 백그라운드에서 카페 전체나 열지 않은 게시글 수집 |
| 사용자 | SOOP 항목 재생 | 수집 목록에서 직접 재생·이전·다음·일시정지·이어서 재생 선택, 자동 넘기기 명시적 설정 | 자동 넘기기 기본 활성화 또는 사용자 설정 없이 다른 영상으로 이동 |
| 확장 | 카페 내용 읽기 | `cafe.naver.com`의 현재 로드된 프레임 안에서 링크·텍스트 추출 | 페이지의 HTML 또는 댓글 내용을 코드로 실행 |
| 확장 | SOOP 페이지 제어 | 허용 호스트와 플레이어 경로 검증을 통과한 URL | 유사 도메인 허용, 접근 제한 우회, 광고 제거·건너뛰기 자동화 |
| 외부 시스템 | 저장 데이터 접근 | 허용 없음 | 카페 원문, 작성자, 목록, 재생 상태 수신 |

## 인증과 실패 경로

확장은 자체 로그인이나 자격 증명을 만들지 않는다. 네이버와 SOOP 로그인·세션·접근 권한은 각 사이트와 Chrome이 관리한다. 로그아웃, 권한 부족, 삭제된 글·영상처럼 사이트가 접근을 거부하면 확장도 데이터를 얻지 못한 상태로 끝나야 하며, 쿠키 복사나 별도 요청으로 우회해서는 안 된다.

허용되지 않은 URL은 탭을 열기 전에 거부한다. 본편을 60초 안에 찾지 못하거나 영상 길이를 벗어난 구간이면 미디어를 조작하지 않고 항목 오류를 표시한다. 자동 재생이 거부되면 사용자 조작 안내만 표시한다.

## 권한과 기록

호스트 권한은 네이버 카페와 SOOP VOD 두 도메인 계열로 제한한다. 저장 권한은 목록, 활성 번호, 사용자 재생 옵션을 기기 안에 유지하는 데만 사용한다. 별도 감사 로그나 원격 진단 기록은 남기지 않는다.
