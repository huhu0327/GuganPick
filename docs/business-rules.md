# 제품 규칙

## 사용자와 입력 범위

- 확장 프로그램은 스트리머가 설치한다. 제보자는 별도 프로그램이나 계정을 사용하지 않는다.
- 영상 후보는 사용자가 열어 둔 네이버 카페 게시글의 본문과 현재 로드된 댓글에서만 찾는다. 다른 게시글, 아직 펼치지 않은 댓글, 카페 전체 게시판을 자동 수집해서는 안 된다.
- 시간 범위는 SOOP 링크와 같은 본문 컴포넌트 또는 같은 댓글에 있어야 한다. 다른 댓글의 시간을 임의로 링크와 결합해서는 안 된다.
- SOOP 구간 패널은 현재 영상 게시자가 직접 작성한 SOOP 댓글의 시간 범위만 표시한다. 양쪽 계정 ID를 읽을 수 있으면 ID를 우선 비교하고, 한쪽 ID가 없으면 공백을 정규화한 표시 닉네임을 비교한다. 다른 작성자의 댓글, 카페에서 저장한 항목, 시간 범위가 없는 현재 페이지 대체 항목은 섞지 않는다.

## 영상과 시간

- 유효한 영상은 `vod.sooplive.com` 또는 `vod.sooplive.co.kr`의 `/player/{숫자}`이며 선택적인 `/catch` 경로를 가질 수 있다. 같은 숫자라도 일반 플레이어와 `/catch`는 서로 다른 영상 식별자로 취급한다. 다른 호스트나 다른 경로는 영상 후보가 아니다.
- `분:초`는 1~3자리 분과 2자리 초를 사용하며 초는 00~59여야 한다. `시:분:초`는 1~3자리 시와 2자리 분·초를 사용하며 분·초는 각각 00~59여야 한다. 시작은 종료보다 작아야 한다.
- 지원하는 범위 모양과 일치하지만 값이 범위를 벗어나거나 시작·종료 순서가 잘못되면 오류 항목으로 표시한다. 지원하는 모양 자체와 일치하지 않는 시간 비슷한 텍스트는 구간으로 해석하지 않는다.
- 같은 영역에 유효한 시간 범위가 있으면 범위의 시작점이 URL의 `change_second` 또는 `start`보다 우선한다. 범위가 없고 시작 쿼리가 0 이상의 숫자면 그 시각부터 재생하며 두 쿼리가 함께 있으면 `change_second`를 우선한다.
- 범위와 시작점이 모두 없으면 전체 재생 후보로 표시한다. 구간이 없다는 이유로 링크를 버리거나 임의의 시작·종료 시각을 만들지 않는다.
- 영상 길이를 읽은 뒤 시작점이 길이 이상이거나 종료점이 길이를 넘으면 재생하지 않고 오류로 표시한다.
- 같은 영상 식별자·같은 시작점·같은 종료점은 한 항목으로 합치고 처음 발견한 항목의 제목·출처·작성자를 유지한다. 같은 영상이라도 구간이 다르면 각각 유지한다.

## 재생

- 광고 미디어는 구간 시간 계산 대상이 아니다. 본편이 준비된 뒤에만 시작 위치를 설정한다.
- 광고가 없고 본편이 이미 준비됐으면 고정 폴링 주기를 기다리지 않고 시작 위치를 설정해 재생한다.
- 현재 영상 게시자의 댓글 중 하나에 정확한 표식 `[봤]`이 있으면 별도 댓글이어도 구간 목록 전체를 반투명 검정 오버레이 하나로 덮고 중앙에 `- 봤 -`을 한 번만 표시하며 재생·타임스탬프 클릭 대상에서 제외한다.
- `구간마다 멈추기`는 기본 켜짐이며 켜면 선택 구간의 종료점에서 일시정지한다. 다음 유효 구간이 있으면 확인 팝업을 표시하고 사용자가 선택한 경우에만 해당 구간을 재생한다.
- `구간마다 멈추기`가 꺼져 있고 `마지막 구간 멈추기`가 켜져 있으면 재생 시작 당시 마지막 유효 구간 종료점에서 일시정지한다. 둘 다 꺼져 있으면 계속 재생하며 어떤 옵션도 다음 구간이나 다음 영상을 자동 재생하지 않는다.
- 활성 구간의 상태와 일시정지/이어서 재생 버튼은 확장 버튼과 SOOP 플레이어 자체 조작을 포함한 본편 미디어의 실제 재생 상태를 따른다.
- 브라우저가 자동 재생을 거부하면 사용자의 SOOP 재생 조작을 기다리고 오류 원인을 표시한다. 사용자 동작을 우회해 재생을 강제해서는 안 된다.
- `첫 구간 자동 재생`은 기본 켜짐이며, 사용자가 끄지 않으면 현재 영상 게시자의 첫 유효 댓글 구간을 페이지당 한 번 기존 광고·본편 준비 경로로 재생한다.
- 구간 카드의 시작·종료 타임스탬프는 각각 해당 초부터 재생할 수 있으며, 선택 구간이 완료되면 다음 구간을 선택할 때까지 하이라이트와 완료 상태를 유지한다.
